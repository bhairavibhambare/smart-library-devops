# Smart Library Management Platform

## Project Overview
This project demonstrates automated AWS infrastructure provisioning
and web application deployment using Terraform, Ansible, Docker, and Git.

## Technology Stack
- AWS EC2, VPC, Security Groups, and S3
- Terraform
- Ansible
- Docker
- Git and GitHub

## Project Structure
- terraform/: AWS infrastructure configuration
- ansible/: Server configuration and deployment automation
- app/: Web application
- docs/screenshots/: Project evidence and screenshots
